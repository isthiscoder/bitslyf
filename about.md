**Discover. Predict. Build.** Bitslyf is a research lab on industries, from how they work to what to build next.

The name joins *bits*, the basic principles of how technology works, with *lyf*, the human life it shapes.

## How the work moves

Every question goes through five logs, each one building on the last.

| | Log | What it answers |
|---|---|---|
| **Discover** | [Analysis](/analysis/) | How does this industry's workflow actually run today? |
| | [Research](/research/) | What would change if one part of it changed? |
| **Predict** | [Prediction](/prediction/) | Will it happen, by when, and how sure are we? |
| | [Thesis](/thesis/) | Where is the whole industry heading? |
| **Build** | [RFS](/rfs/) | What should someone build because of it? |

## Scored in public

Every prediction has a number, a date, and a named source that settles it. When it resolves, the result is added and nothing is rewritten. The misses stay up, and the full record is on the [scorecard](/scorecard/).
